# RoseOS frankel 2026102804 — draft candidate

This is a draft release candidate. It is not promoted: the existing Beta channel
(pixel-ota Latest) is unchanged, and this build is not offered on Alpha or Prod.

- Target: frankel (Pixel 10), user build, signed with the existing release identities
  (same app signer, OTA certificate and AVB key as the current Beta release).
- Expected apps: Rose Agent (dev.pixel.voice) versionCode 302 (302-wave-beta),
  background controller (dev.pixel.backgroundcontrol) 28 (2.1.5-pip, unchanged),
  Calculator Agent (dev.pixel.calculator.agent) 4 (unchanged).
- Rose Agent keeps the existing public connection settings and the existing server.
  Signing, security, trust and update-channel settings are unchanged.
- The background controller keeps locked sessions off and its prototype agent list
  empty.

Included since the 2026102803 draft:

- The system Updater is built into the image again. The 2026102803 draft shipped
  without it, so its Prod, Beta and Alpha channel choices could not be used. The
  Updater keeps the existing pixel-ota feed, defaults to Prod for new installs and
  publishes only the existing Beta (stable) channel.
- Update Rose Agent can install a verified newer Rose Agent itself.
- Release checks now require the system Updater in the signed image: its package,
  its permission files, its compiled feed and channel settings, its RoseOS channel
  code and its release-key signature.

Also included from 2026102803 and earlier drafts: WebView renderer recovery, voice
page callbacks bound to their page, Watch opening the selected task and session, the
recheck of each fetched phone command, truthful single outcomes for slow commands,
the launcher Home page and Rose entry, the voice conversation surface with task
progress and Stop, the Rose Agent status tray, the Update Rose Agent check, spoken
server task progress, and ignoring retained events on page load.

This build has not been accepted on a phone. The Updater's channel choices and update
check, Rose Agent's self-update install, Watch attaching to and recreating the viewer,
and native timeout scheduling are not yet verified at runtime; nothing here claims
runtime or installation results.
