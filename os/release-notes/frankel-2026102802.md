# RoseOS frankel 2026102802 — draft validation candidate

This is a draft release built only to validate the OS release pipeline. It is not
promoted: the existing Beta channel (pixel-ota Latest) is unchanged, and this build
is not offered on Alpha or Prod.

- Target: frankel (Pixel 10), user build, signed with the existing release identities
  (same app signer, OTA certificate and AVB key as the current Beta release).
- Expected apps: Rose Agent (dev.pixel.voice) versionCode 300 (300-wave-beta),
  Calculator Agent (dev.pixel.calculator.agent) 4, background controller
  (dev.pixel.backgroundcontrol) 27.
- Rose Agent uses the existing public connection settings.

Included since 2026102701:

- Launcher Home page in front of the Rose conversation, with a Rose entry that
  opens the conversation surface and shows the voice session.
- Voice conversation surface showing the current task's progress and result, with
  watching and stopping the selected task from the conversation.
- Rose Agent status tray in the system image, driven by the conversation state.
- System Updater with Prod, Beta and Alpha channel choices on the existing pixel-ota
  feed, and an Update Rose Agent check in the conversation menu.
- Server task progress and failure lines spoken again.

This build has not been accepted on a phone; nothing here claims runtime or
installation results.
