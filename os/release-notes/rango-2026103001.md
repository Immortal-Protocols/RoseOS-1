# RoseOS rango 2026103001 — first Pixel 10 Pro Fold Beta (manual installation)

This is the first RoseOS build for the Pixel 10 Pro Fold. It is published as its own
release, rango-2026103001. It is never the pixel-ota Latest release and is not offered
to any phone automatically.

- Target: rango (Pixel 10 Pro Fold), user build, Android 17 (SDK 37), CP3A.261005.005,
  security patch 2026-10-05, compiled 2026-10-30 02:49:07 UTC.
- Expected apps: Rose Agent (dev.pixel.voice) versionCode 310, background controller
  (dev.pixel.backgroundcontrol) 28, Calculator Agent (dev.pixel.calculator.agent) 4,
  the same app bytes and app signer as the Pixel 10 Beta.
- The background controller keeps locked sessions off and its prototype agent list
  empty.
- Signed with its own Fold OTA and AVB identity, separate from the Pixel 10 (frankel)
  identity. It is not an update for a Pixel 10, and Pixel 10 builds do not install
  on it.

Manual installation only:

- Install this build by hand from the release assets. RoseOS on-device update
  discovery is not included: the system Updater keeps its upstream configuration and
  is not set up for any RoseOS channel, so the phone will not find later RoseOS
  builds by itself. Later Fold builds also need a manual install until RoseOS update
  integration for the Fold ships.
- The rango-stable file in the release describes this build; nothing on the phone
  reads it.

The release is published only after the signed build passes verification. This build
has not been accepted on a phone; installation, Home, the Rose tray and the agent
features on the Fold are untested.
