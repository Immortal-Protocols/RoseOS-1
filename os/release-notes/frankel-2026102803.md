# RoseOS frankel 2026102803 — draft candidate

This is a draft release candidate. It is not promoted: the existing Beta channel
(pixel-ota Latest) is unchanged, and this build is not offered on Alpha or Prod.

- Target: frankel (Pixel 10), user build, signed with the existing release identities
  (same app signer, OTA certificate and AVB key as the current Beta release).
- Expected apps: Rose Agent (dev.pixel.voice) versionCode 301 (301-wave-beta),
  background controller (dev.pixel.backgroundcontrol) 28 (2.1.5-pip),
  Calculator Agent (dev.pixel.calculator.agent) 4 (unchanged).
- Rose Agent keeps the existing public connection settings and the existing server;
  no server, protocol or security change is part of this build.
- The background controller keeps locked sessions off and its prototype agent list
  empty.

Included since the 2026102802 draft:

- Every app WebView recovers from a lost renderer instead of staying blank.
- Voice page callbacks are bound to the page that registered them, so a reloaded
  page no longer receives a previous page's events.
- Watch opens the agent viewer on the task and session selected in the
  conversation, and the viewer stays on that task and session.
- Each phone command fetched from the server is checked again just before it runs.
- A slow phone command reports its real outcome, and its action runs only once.

Also included from 2026102802: the launcher Home page and Rose entry, the voice
conversation surface with task progress and Stop, the Rose Agent status tray, the
Prod/Beta/Alpha Updater channels, the Update Rose Agent check, spoken server task
progress, and ignoring retained events on page load.

This build has not been accepted on a phone. Watch attaching to and recreating the
viewer, and native timeout scheduling, are not yet verified at runtime; nothing here
claims runtime or installation results.
