# RoseOS frankel 2026102901 — Beta candidate

This is a release candidate for the Beta channel. It is not promoted: the existing Beta
channel (pixel-ota Latest, 2026102806) is unchanged, and this build is not offered on
Alpha or Prod.

- Target: frankel (Pixel 10), user build, signed with the existing release identities
  (same app signer, OTA certificate and AVB key as the current Beta release).
- Expected apps: Rose Agent (dev.pixel.voice) versionCode 310 (310-hifi-os-beta),
  background controller (dev.pixel.backgroundcontrol) 28 (2.1.5-pip, unchanged),
  Calculator Agent (dev.pixel.calculator.agent) 4 (unchanged).
- Rose Agent keeps the existing public connection settings and the existing server.
  Signing, security, trust and update-channel settings are unchanged.
- The background controller keeps locked sessions off and its prototype agent list
  empty.

Included since 2026102806:

- Home has a fixed tray with Rose and an overview button that stays in place while
  the pages swipe beneath it. The overview button is shown but not available yet.
- The pages of installed apps now sit next to Home, and pressing Home after using an
  app or the Rose conversation returns to the page you left.
- Rose in the Home tray and on the conversation screen is drawn from the actual
  connection, microphone and Rose's voice, and stays still with reduced motion or
  while Home is hidden. Tapping Rose only opens the conversation.
- The conversation screen follows the new Rose design.
- Update Rose Agent lists Alpha, Beta and Prod explicitly; only Beta is configured,
  so it stays the one that offers updates.

This build has not been accepted on a phone. The new Home tray and pages, Rose's
animation and the conversation screen are not yet verified at runtime; nothing here
claims runtime or installation results.
