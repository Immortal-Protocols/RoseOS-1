# RoseOS frankel 2026102805 — Beta candidate

This is a release candidate for the Beta channel. It is not promoted: the existing Beta
channel (pixel-ota Latest, 2026102804) is unchanged, and this build is not offered on
Alpha or Prod.

- Target: frankel (Pixel 10), user build, signed with the existing release identities
  (same app signer, OTA certificate and AVB key as the current Beta release).
- Expected apps: Rose Agent (dev.pixel.voice) versionCode 305 (305-home-beta),
  background controller (dev.pixel.backgroundcontrol) 28 (2.1.5-pip, unchanged),
  Calculator Agent (dev.pixel.calculator.agent) 4 (unchanged).
- Rose Agent keeps the existing public connection settings and the existing server.
  Signing, security, trust and update-channel settings are unchanged.
- The background controller keeps locked sessions off and its prototype agent list
  empty.

Included since 2026102804:

- Rose Agent becomes the Home app once for each user, on the first start of this
  build. That covers a new phone and a phone updated from 2026102804. The change is in
  the system's role service, which ships in the Permission module (com.android.permission),
  and it makes the same selection as Settings > Default apps > Home app. It runs only once
  for each user, so a Home app the owner picks later stays. If Rose Agent is missing or
  disabled, the current Home app stays.
- The Rose Agent app icon opens Rose Home with the Rose conversation on top, and Back
  returns to Rose Home.
- Update Rose Agent downloads a newer Rose Agent only from RoseOS's own GitHub release
  location. It checks the download's size and SHA-256 before installing.
- Release checks now require the Permission module in the image to be built from the
  patched source: its name, version, Home-selection code, payload signature and
  release-key signature.

This build has not been accepted on a phone. The Home selection after an update, at first
boot and after a reboot, a later owner choice of Home app, and the Rose Home screen itself
are not yet verified at runtime; nothing here claims runtime or installation results.
