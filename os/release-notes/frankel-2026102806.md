# RoseOS frankel 2026102806 — Beta candidate

This is a release candidate for the Beta channel. It is not promoted: the existing Beta
channel (pixel-ota Latest, 2026102805) is unchanged, and this build is not offered on
Alpha or Prod.

- Target: frankel (Pixel 10), user build, signed with the existing release identities
  (same app signer, OTA certificate and AVB key as the current Beta release).
- Expected apps: Rose Agent (dev.pixel.voice) versionCode 308 (308-home-tray-beta),
  background controller (dev.pixel.backgroundcontrol) 28 (2.1.5-pip, unchanged),
  Calculator Agent (dev.pixel.calculator.agent) 4 (unchanged).
- Rose Agent keeps the existing public connection settings and the existing server.
  Signing, security, trust and update-channel settings are unchanged.
- The background controller keeps locked sessions off and its prototype agent list
  empty.

Included since 2026102805:

- The status bar's Agent tray stops its updates while the screen is off and picks
  them up again with fresh state when the screen comes back on, so Rose Agent stops
  polling for the tray while the screen is off. Voice and tasks are not affected.
- Pressing Home, or returning to Rose Agent from its icon, reuses the Home screen
  that is already built instead of rebuilding it each time. It still rebuilds when
  apps, the screen settings or the default apps change.
- The Home menu no longer offers the three trial switches (DeepSeek Fast, Luna-first
  voice, ARTEMIS phone control). Stored settings are left as they are, and a backend
  that already has one of them turned on keeps it and still reports it.
- Home dock labels fit whole instead of being cut off.
- Update Rose Agent checks for and installs newer Rose Agent releases directly from
  RoseOS's public GitHub releases, verifying size, SHA-256 and signer.
- Release checks now also require the Agent tray's screen-off code in the image's
  System UI.

This build has not been accepted on a phone. The tray pausing at screen-off and
resuming at screen-on, Home reuse on a HOME press, and the direct update check are
not yet verified at runtime; nothing here claims runtime or installation results.
